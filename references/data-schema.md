# lessons.json 数据结构

构建脚本的唯一输入。一个 JSON 对象描述一整本教材。

## 顶层字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `textbook` | ✅ | string | 教材全名，显示在页面标题与副标题 |
| `lessons` | ✅ | array | 课次数组，见下文 |
| `id` | 建议 | string | 打卡键前缀，ASCII 小写（如 `minna2`）。省略时从教材名自动生成。**不同教材必须不同**，否则打卡进度会互相覆盖 |
| `checks` | 可选 | string[] | 打卡项，默认 `["单词过了一遍","语法看懂了","练习做完并对过答案"]` |
| `note` | 可选 | string | 显示在首页「说明」卡片里的提示文字 |
| `workbenchTitle` | 可选 | string | 首页大标题，默认「日语学习工作台」 |

## lesson 字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | int | 课次编号，须全局唯一 |
| `title` | ✅ | string | 本课主题，如「可能动词・見えます・聞こえます」 |
| `src` | 可选 | string | 原文出处，如「书页 14–19（PDF 35–40）」 |
| `words` | ✅ | object | 单词表，按类别分组，见下 |
| `grammar` | 可选 | array | 语法条目 |
| `exercises` | 可选 | array | 练习题 |
| `groupNote` | 可选 | string | 本课作为所在页首课时，显示在首页课组卡片上的灰色小字 |

### words：单词分组

键名即分类名，顺序即页面展示顺序。以下为标准分类（可按教材增减，但 `動詞` 必须保持此键名）：

- `動詞`
- `名詞`
- `い形容詞`
- `な形容詞`
- `副詞・助詞・接尾`
- `寒暄・表現`

**`動詞` 的行固定 5 项**：

```json
["遅れます", "⓪", "遅れる", "動Ⅱ", "晚了、没赶上（時間に遅れます）"]
```

依次为 `ます形`、`音调`、`辞书形`、`类型`、`释义`。类型只能是 `動Ⅰ` / `動Ⅱ` / `動Ⅲ`。音调未知填 `"—"`。辞书形若有并列写法用 `/` 分隔（如 `見る/診る`），脚本取第一个推导变形。

**其他分类的行固定 4 项**：

```json
["ゴミ", "ごみ", "②", "垃圾"]
```

依次为 `单词`（汉字或片假名）、`读音`（平假名，外来语填 `"—"`）、`音调`、`释义`。

释义里可放进简短的搭配提示，如 `"受欢迎（〔学生に〕～があります）"`。辅导用书补充词建议在词首加 `▲` 以示区分。

### grammar：语法条目

```json
{
  "pattern": "动词て形 いただけませんか",
  "name": "能帮我……吗？（礼貌的请求）",
  "desc": "比「～て ください」更礼貌的请求表达。",
  "examples": [
    ["いい 先生を 紹介して いただけませんか。", "您能帮我介绍一位好老师吗？"]
  ],
  "note": "第41课的「～て くださいませんか」礼貌程度更高。"
}
```

- `pattern` 写接续形式，是页面上蓝色条块里的标题
- `name` 一句话点明作用
- `desc` 可含 `<b>` 强调，但不要用 `<br>`（脚本会转空格）
- `examples` 每项 `[日文, 中文]`
- `note` 可选，黄色提示块

### exercises：练习题

```json
{ "type": "选择", "q": "頭が 痛いんです（　）、帰っても いいですか。　A が　B から　C のに", "a": "A。～んですが 用于提起话头，后面接请求许可。" }
```

`type` 常用值：`选择` `填空` `变形` `改写` `翻译` `判断`。答案里写清理由，而不只是给选项。

## 完整最小示例

```json
{
  "id": "minna2",
  "textbook": "大家的日语 初级2（第二版）",
  "note": "第 1–25 课暂无整理材料。",
  "lessons": [
    {
      "id": 27,
      "title": "可能动词・見えます・聞こえます",
      "src": "书页 14–19（PDF 35–40）",
      "groupNote": "んです・可能动词・ながら・てあります",
      "words": {
        "動詞": [
          ["見えます", "②", "見える", "動Ⅱ", "看见（山が見えます）"],
          ["飼います", "①", "飼う", "動Ⅰ", "饲养（犬を飼います）"]
        ],
        "名詞": [
          ["鳥", "とり", "⓪", "鸟"],
          ["ペット", "—", "①", "宠物"]
        ],
        "い形容詞": [
          ["素晴らしい", "すばらしい", "④", "很棒、很好"]
        ],
        "な形容詞": [],
        "副詞・助詞・接尾": [
          ["はっきり", "—", "③〈副〉", "清楚地"]
        ],
        "寒暄・表現": [
          ["山が見えます。", "—", "—", "看见山。"]
        ]
      },
      "grammar": [
        {
          "pattern": "～が 可能动词",
          "name": "可能动词表示状态，对象由「を」变「が」",
          "desc": "可能动词表示的是<b>状态</b>而不是动作，对象原则上用「が」。",
          "examples": [
            ["わたしは 日本語が 話せます。", "我能说日语。"],
            ["一人で 病院へ 行けますか。", "你能一个人去医院吗？"]
          ],
          "note": "「を」以外的助词不变。"
        }
      ],
      "exercises": [
        {
          "type": "选择",
          "q": "わたしは 日本語（　）話せます。　A を　B が　C に",
          "a": "B。可能动词的对象原则上用「が」。"
        }
      ]
    }
  ]
}
```

## 校验规则

构建脚本会检查：根节点是对象、`textbook` 非空、`lessons` 为非空数组、每课有 `id` 与 `title`、`words` 是对象、`id` 不重复。任一项不通过会列出全部错误并退出，不会产出半成品。
