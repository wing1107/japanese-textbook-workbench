# 从教材提取内容

目标是把教材变成 `lessons.json`。这一步只能靠读原文，不能凭记忆补。

## 一、先摸清排版规律

不要一上来就逐页读完整本。先做三件事：

1. **定位目录页**，拿到课次列表与起始页。
2. **精读一课**（通常是最短的一课），确认固定栏目：文法、例文、会話、単語、練習 各在哪一段。
3. **算出页码偏移**：教材印刷页码与 PDF 物理页码常常差 20 页左右。`src` 字段同时记两者，如 `书页 14–19（PDF 35–40）`，以后回溯原文最省事。

规律确认后，再按同样的栏目顺序批量读取，速度会快很多。

## 二、读取策略

- 用 `Read` 直接读 PDF，它会按页解析文字与版式。
- 一次读 10–15 页较稳。整本一次读入容易触发长度截断，反而丢内容。
- 页数很多时，先用 pypdf 按课或按 50 页拆分，再逐份读取：

```python
from pypdf import PdfReader, PdfWriter
r = PdfReader("book.pdf")
for i in range(0, len(r.pages), 50):
    w = PdfWriter()
    for p in r.pages[i:i+50]:
        w.add_page(p)
    with open(f"part_{i//50+1}.pdf", "wb") as f:
        w.write(f)
```

- 扫描版（图片型）PDF 没有文字层，`Read` 会把页面当图片看，这仍然可用，但要更仔细核对片假名与长音符。

## 三、单词表提取

### 分类归属

按教材原栏目对号入座：

| 教材栏目 | 归入 |
|---|---|
| 動詞 / 动词 | `動詞` |
| 名詞 / 名词 | `名詞` |
| い形容詞 / イ形 | `い形容詞` |
| な形容詞 / ナ形 | `な形容詞` |
| 副詞・接続詞・助詞・接尾辞 | `副詞・助詞・接尾` |
| 挨拶・表現 / 寒暄语 | `寒暄・表現` |

教材若分成「新出単語」和「補充単語」，可在补充词首加 `▲`，页面上会用不同样式标出。

### 音调记号

教材常用圈码 `⓪①②③④⑤` 表示音调核位置：

- `⓪` 平板型
- `①` 头高型
- `②③…` 中高／尾高

若教材未标注，填 `"—"`，不要自己推测。

### 动词类型判定

优先用教材标注（多数教材在词后标 `Ⅰ/Ⅱ/Ⅲ` 或 `1/2/3 类`）。没有标注时按规则推断：

- **動Ⅲ**：`する`、`～する`（勉強する）、`来る`、`～てくる`
- **動Ⅱ**：以 `る` 结尾，且 `る` 前一个假名在 `い段` 或 `え段`（食べる、見る、寝る）
- **動Ⅰ**：其余全部

**動Ⅱ 的常见例外**（外形像二类，实为一类，必须记为一类）：
`入る` `走る` `帰る` `切る` `知る` `要る` `限る` `滑る` `蹴る` `握る` `減る` `焦る` `参る` `散る` `照る`

判定错了，变形表整行都会错，这是最需要复核的地方。

## 四、语法条目提取

每课通常有 3–6 个语法点。每个点拆成五块：

1. **pattern** — 接续形式，照抄教材标题，如「動詞て形 いただけませんか」
2. **name** — 一句话说清"用来干什么"，如「能帮我……吗？（礼貌请求）」
3. **desc** — 教材讲解正文。保留接续规则、使用场景、与近义句型的区别。可用 `<b>` 强调关键词。
4. **examples** — 教材例句，中日对照。至少 2 条；若教材只给 1 条，就只写 1 条，不要自己造。
5. **note** — 教材里的「〔注〕」提醒，或跨课对照（如"第 41 课有更礼貌的说法"）。

教材原文里的 `<` `>` `&` 会被脚本转义，正常书写即可。

## 五、练习题提取

优先收教材「練習」栏目的题。题型建议覆盖：

- **选择**：辨析近义句型、助词
- **填空**：接续形式
- **变形**：动词／形容词活用
- **改写**：主动↔被动、普通体↔礼貌体
- **翻译**：中→日
- **判断**：给一个错句，判断并说明为什么错

答案要写"为什么"，不只写选项。例如：

> ✗。「んです」只用于说明理由或确认；单纯叙述事实（自我介绍）不用「んです」→ わたしは マイク・ミラーです。

## 六、常见陷阱

| 陷阱 | 应对 |
|---|---|
| 振假名混进正文，导致「漢字（かんじ）」重复 | 只保留一种写法。正文留汉字，读音放单词表的读音列 |
| 双栏排版，文字顺序错乱 | 按栏分别读取，再按语义拼接 |
| 印刷页码 ≠ PDF 页码 | `src` 同时记录两者 |
| 会话文里的口语缩略（～ちゃう、～じゃ） | 照原文保留，不要"纠正"成书面形 |
| 教材用「Ⅰ类/Ⅱ类/Ⅲ类」而非「動Ⅰ」 | 统一映射到 `動Ⅰ/動Ⅱ/動Ⅲ` |
| 补充词汇混入正文 | 加 `▲` 前缀区分 |

## 七、交付前自查

- [ ] 课次数与教材目录一致，编号连续无重复
- [ ] 每课至少有 `words`，`動詞` 的每行都是 5 项
- [ ] 动词类型抽查 10 个，尤其上面列出的二类例外
- [ ] 语法条目数与本课实际语法点数量吻合
- [ ] 例句的中文翻译与日文一一对应，没有错位
- [ ] 没有出现教材里不存在的词条或语法点
